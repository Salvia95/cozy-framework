# ADR-0012 v1부터 자체 업데이트 장치 포함

- 상태: 승인 (2026-11-05)
- 출처: PRD §3 D12

## 결정

v1부터 매니페스트 기반 자체 업데이트(검증, 교체, 롤백)를 포함한다.

## 근거

- app-image는 스스로 갱신하지 못한다.
- 업데이트 장치가 없으면 v2를 배포하는 경로가 수작업뿐이다.

## 결과

- 구현은 M6에서 했다. 세부 결정은 ADR-0024, 사용법은 docs/conventions/distribution.md에 있다.
- 실제 app-image의 업데이트·롤백은 종단 검증(`mvn -Pe2e install`)이 확인한다. Windows에서는 사용자가 같은 검증을 돌린다.
